Infusion & Field Reloading

Infusion is the process of placing a Symbol into a compatible Spell Slot. The stored Technique remains there until the practitioner activates it.

The basic process

  1. Learn the Technique. The practitioner studies the ability in its divine tradition.
  2. Obtain or create a Symbol. The Symbol represents one prepared use of that learned Technique.
  3. Choose a compatible Slot. The Template must be blank or already belong to the Symbol’s same Source.
  4. Install the Symbol. It is placed onto the physical Slot, becoming part of that Slot.
  5. Retain or activate. The use remains stored until the user triggers it; activation consumes the Symbol and leaves the Slot empty.

Compatibility check

The first Symbol placed in a blank Template establishes the Template’s divine association. Every later Symbol must belong to that same god or Source. An empty Slot in an already claimed Template is not a free pass to introduce a second tradition.

Installation is not authority

A person can install a normal, non-blood-bound Symbol into a blank Template even if someone else is physically holding that object. Installation determines what is stored. Authority determines who may activate it.

Reloading under pressure

After use, the vanished Symbol leaves an empty Slot. Prepared Symbols—especially film formats—let a trained practitioner refill it. A small number of Templates can therefore support many configurations across a prolonged engagement.
